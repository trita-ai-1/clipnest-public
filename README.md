# ClipNest public resources

ClipNest is an Android video downloader by **tritalabs**.

- [Privacy policy](https://trita-ai-1.github.io/clipnest-public/privacy.html)
- [Third-party sources for version 3.2](https://github.com/trita-ai-1/clipnest-public/releases/tag/v3.2)
- Support: contact@tritalabs.com

This public repository contains the privacy policy and third-party dependency source materials only. ClipNest application source code is private and is not included here.

The current privacy policy covers the ad-free release. Advertising disclosures must be updated before distributing an ads-enabled version. Each third-party component retains its own license, as documented in the source archive.
