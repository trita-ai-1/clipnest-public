# ClipNest public resources

ClipNest is an ads-supported Android video downloader by **tritalabs**.

- [Privacy policy](https://trita-ai-1.github.io/clipnest-public/privacy.html)
- [Third-party sources for version 3.2](https://github.com/trita-ai-1/clipnest-public/releases/tag/v3.2)
- Support: contact@tritalabs.com

This repository hosts public privacy and dependency materials only. ClipNest application source is private and is not included here.

The privacy policy covers the ads-enabled release using Google AdMob and UMP. Each third-party component retains its own license, as documented in the dependency-source archive.
